# STM32 Blue Pill – Learning & Development

This repository documents my journey of learning and experimenting with the **STM32 microcontroller family**, using the **STM32F103C8T6 (Blue Pill)** development board.

The main goal of this project is to gain practical experience in embedded systems development, covering both hardware design and firmware programming.

## Project Goals

- **PCB Design:** Designing a custom Blue Pill PCB from scratch, including schematic design and PCB layout.
- **STM32CubeMX:** Configuring microcontroller peripherals, clocks, GPIOs, timers, communication interfaces, and other hardware resources.
- **Keil MDK:** Developing, compiling, and debugging embedded C firmware.
- **Proteus Simulation:** Simulating circuits and testing firmware behavior in a virtual environment.

## Tools & Technologies

- **Microcontroller:** STM32F103C8T6
- **IDE:** Keil MDK-ARM
- **Configuration Tool:** STM32CubeMX
- **Simulation:** Proteus
- **Programming Language:** Embedded C
- **Hardware Design:** PCB Design & Schematic Capture

## Learning Roadmap

1. Understanding STM32 architecture and peripherals.
2. Designing a custom Blue Pill PCB.
3. GPIO configuration and digital I/O programming.
4. Working with timers, interrupts, and PWM.
5. Serial communication protocols (UART, SPI, I2C).
6. ADC and other peripheral modules.
7. Hardware testing and Proteus simulation.
8. Building practical embedded systems projects.

## Purpose

This is a hands-on learning project focused on developing practical skills in **embedded systems, microcontroller programming, and PCB design**.

All designs, source codes, experiments, and simulation files will be documented and uploaded here as the project progresses.
